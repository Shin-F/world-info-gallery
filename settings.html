World Info Gallery
Covers are uploaded to the server under /user/images/worldinfo-gallery/. Folders are stored inside each lorebook as a per-entry wig_folder field, so they survive ST updates and travel with the file on export/import.
Chat links are remembered automatically, so lorebooks keep their chat badge after you leave the chat. "Scan all chats" re-reads every chat file once to backfill links made before the extension was installed.
